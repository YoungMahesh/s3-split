# S3-Split

A multi-tenant platform that partitions S3-compatible storage into managed buckets with strictly enforced storage quotas using an S3 gateway proxy.

## Language

**Upstream Account**:
The external S3 provider credentials (access key, secret key, endpoint URL, and region) configured by the platform user.
_Avoid_: S3 credentials, remote account, provider config

**Managed Bucket**:
A storage target (either an upstream physical bucket or an isolated virtual prefix) governed by a specific byte quota.
_Avoid_: Capped bucket, sub-bucket, folder

**Client Key**:
The custom access key pair (access key ID and secret access key) generated by our platform for downstream applications to authenticate against the S3 gateway.
_Avoid_: Custom credentials, virtual credentials, app token

**Storage Quota**:
The maximum byte capacity allocated to a Managed Bucket.
_Avoid_: Cap, limit, maximum storage

**Managed Object**:
An indexed representation of an object stored in a Managed Bucket, tracking its key, byte size, and checksum.
_Avoid_: File, blob, S3 record

**Part Reservation**:
A temporary byte allocation reserved during an active multipart upload to prevent over-quota breaches before completion.
_Avoid_: Pending bytes, chunk lock
